One weird idea: put the agent inside the app

Today: a chatbot bolted on

The app is fixed. The assistant sits in a side panel, can talk about the app, and cannot change it.

ACRYL: the agent is a plugin

It reads the app, runs it, and changes it while it runs. Ask for a feature and it ships as a plugin, live.

Your models, your data, your machine, your git. MIT, on GitHub and npm.

0:30 - Most AI products bolt a chatbot onto a fixed app. We start the other way around: every app is built from plugins, and the agent is one of them.

Ask. It writes the plugin. It is live.

Why it does not break: every plugin comes with its undo

Verified first

A plugin is checked before it installs, and the agent tests what it built.

Reverted cleanly

A plugin that fails detaches and leaves no trace. The running app keeps running.

Pinned

Every plugin is locked by version and checksum, so two machines do not drift apart.

Switch it off

Add, swap or remove a plugin without forking anything. Back in time, any time.

The kernel is Cordis, a plugin system with lifecycles and effects that load, unload and replace live. It also runs under DeepSeek Harness.

2:00 - The obvious fear: an agent editing a live app. The answer is the plugin system. Every effect has a disposer, so removing a plugin undoes what it did.

An app is one file. Share it.

  • rows: the plugins and their config
  • extends: start from anyone's app, override only what differs
  • a lock pins every plugin by version and checksum
  • push to git or a registry; others pull it by name
acryl new my-planner --from acryl.gtd
# registry/blends/acryl.music/blend.yaml (real)
apiVersion: blends.acryl.dev/v1alpha1
kind: Blueprint
metadata:
  id: acryl.music
  name: Music
  version: 0.1.0
  category: creative
  license: MIT
  visibility: public
spec:
  runtime: cordis
  extends: acryl.blank
  rows:
    - id: brand
      name: acryl-brand
      config:
        name: Music
        tagline: Say the beat, hear the beat.
    - id: acryl-music
      name: acryl-music
4:15 - This is what lets people share what they grow. Write a piece once, everyone reuses it, the lock keeps it reproducible.

The framework: a new agentic app in a minute

npm create acrylblends@latest my-agent agent
cd my-agent && npm install && npm run dev
serves the app and prints its URL

The agent template is a running app whose agent writes and installs plugins into it.

  • A small web framework on Web Standards: one Request in, one Response out
  • Routing, middleware, validation, a typed client, a Node.js server
  • No dependencies. Node 22.19 or newer. MIT
  • Browser, desktop window, or inside the ACRYL frame
5:00 - Getting started is the point. One command, and you own the code: the plugins are files in your folder. npm: acrylblends.

Why you will want it

It writes itself

Ask for a feature your workflow lacks. It becomes a plugin, live.

It repairs itself

The agent tests its work, fixes what is wrong, and a broken plugin is reverted.

It adapts to you

Two people start from the same app and end up with two different apps.

Made of parts

Small plugins you add, swap, remove, version and share. Nothing rebuilt from zero.

Any agent, any model

Claude Code, Codex, DeepSeek, Grok and more. Cordis plugins also run in stock DeepSeek Harness.

Yours and open

Your machine, your data, files you commit to your own git. MIT.
